# NekoRPG
Deep-modified mod of Yet-Another-Idle-RPG

## English translation (this fork)

This branch is an English translation of [btly0711/NekoRPG](https://github.com/btly0711/NekoRPG) at **V3.43c**, continuing the V2.22c translation by [MaxRau](https://github.com/MaxRau/NekoRPG). Translation notes and the term glossary are in `docs/`.

- Saves use the original game's format: exports from this fork load in btly0711's Chinese site (and MedKitty's), and their saves load here. Saves from the older V2.22c English site (maxrau.github.io/NekoRPG) are migrated on import.
- Upstream game logic is unmodified apart from a few lookup helpers so English display names resolve (see `docs/translation-plan.md`).
- Original game: [Miktaew's Yet Another Idle RPG](https://miktaew.github.io/yet-another-idle-rpg/). Story/world: Neko Lulu.
